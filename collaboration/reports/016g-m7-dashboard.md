# Report 016g — M7 read-only investigation dashboard

Branch `task016-m7-dashboard`. Offline only: no model, paid, network or Docker use. No change to grading, investigation logic, frozen manifests or approval gates.

## Verification of the three open questions
1. **Evidence references.** `EvidenceStore.add_hypothesis` rejects unknown citations, so hypothesis→observation links always resolve. A finding's `support` is a list of trial/task refs; it is not enforced to exist (the demo uses placeholder ids). The export resolves each ref against exported trial/task ids and flags unresolved ones; the UI shows them as unresolved.
2. **Trial records.** Per-trial artifacts (`artifacts/trials/baseline-*` / `patched-<proposal>-*`) carry task id, repeat, `outcome.run_status`, evaluation and metrics, so baseline/patched outcomes and void trials (`VOID_STATUSES`) are rebuilt from them. Patched trials are keyed by proposal id from the artifact name.
3. **`report-final`.** Not guaranteed: it exists only after `final_report`; `report` after `report`. The export works from `run.json` + `evidence.jsonl` alone and lists missing artifacts; an unreadable artifact counts as missing.
