# Shared collaboration workspace

This directory is the handoff space between ChatGPT (research/design discussions with the user) and Codex (implementation).

- [proposals](proposals/README.md): exploratory hypotheses and designs; not approved for implementation.
- [tasks](tasks/README.md): user-approved specifications for Codex.
- [reports](reports/README.md): implementation summaries, test results, and questions from Codex.

Workflow: discuss → propose → approve → task → implement → report → review. Approval is explicit, not inferred from the existence of a proposal. GitHub updates do not automatically trigger either assistant.
