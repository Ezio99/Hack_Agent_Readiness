## Act 1: the opening (curious, unhurried)
This is Larkspur Community College.

Beautifully designed. Easy for people to browse.

But what happens when an AI agent tries?

We gave a Meta Muse Spark agent a simple task: find beginner courses that meet on weekends.

It started browsing.

And Agent Readiness was watching.

## Act 2: the investigation (tension builds; quieter at the end)
To answer, the agent needs two facts about every course: its level, and the day it meets.

The catalogue doesn’t show them. They’re on fourteen separate course pages.

So it opens them. One at a time.

Every page costs a step. Every trip back to the catalogue costs another.

Three courses checked. Eleven to go. And its interaction budget is running low.

So it stops itself, before finding all four matching courses. It names just two.

Agent Readiness recorded every step, every screenshot, every decision, and traced the failure to its cause.

The facts the agent needed are on every course page, and on none of the catalogue cards.

## Act 3: the transformation (confident, warm)
The diagnosis was clear. The facts agents need are missing from the catalogue.

Agent Readiness recommended three changes. The first matters most.

Take each course’s facts off its own page, and put them on its catalogue card.

Same design. Same pages. But now every card shows its level, day, fee and seats.

All four weekend beginner courses, visible from one page.

It also fixed a dead end, where an agent’s guessed address led nowhere.

And it described every course in structured data that agents can read directly.

Then the same agent got the same task, on the improved website.
