## Act 1: the opening (curious, unhurried)
This is Larkspur Community College.

Beautifully designed. Easy for people to browse.

But what happens when an AI agent tries?

We gave a Meta Muse Spark agent a simple task: find beginner courses that meet on weekends.

It started browsing.

And Agent Readiness was watching.

## Act 2: the investigation (tension builds; quieter at the end)
The agent needs two facts about every course: its level, and the day it meets.

The catalogue doesn’t show them. They’re on fourteen separate course pages.

So it opens them. One at a time.

Every page costs a step. Every trip back to the catalogue costs another.

Three courses checked. Eleven to go. And its interaction budget is running low.

So it stops itself, before finding all four matching courses. It names just two.

Agent Readiness recorded every step and screenshot, and traced the failure to its cause.

The facts it needed were on every course page, and on no catalogue card.

## Act 3: the transformation (confident, warm)
The diagnosis: the facts agents need are missing from the catalogue.

It recommended three changes. The first matters most.

Take each course’s facts off its own page, and put them on its catalogue card.

Same design. But now every card shows its level, day, fee and seats.

All four weekend beginner courses, visible from one page.

It also fixed a dead end, where an agent’s guessed address led nowhere.

And it described every course in structured data that agents can read directly.

Then the same agent tried again, on the improved website.

## Act 4: the proof (confident; let the numbers land)
In a new evaluation, we ran both versions side by side, on the same tasks.

Before, the agent found just one of four matching courses.

After, it found all four, in three requests, without opening a single course page.

Across the three tasks, correct answers went from zero to three.

Seventy-four percent fewer requests. Eighty-three percent less time. Seventy-seven percent lower cost.

Same agent. A website that finally works for it.

## Act 5: the product and the vision (optimistic, unhurried)
Today, Agent Readiness helps websites understand how AI agents experience them.

Tomorrow, it could help agents discover which websites they can actually use.

Which ones support their task. Which ones are reliable. And where they can succeed.

Agent Readiness.

Building the discovery layer for the agentic web.
